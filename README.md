AI-powered resume analyzer built with Google's Gemini API 
and Bootstrap 5. Paste your resume and instantly get:

Strengths
Weaknesses  
What to Improve
Skills to Add
Best Job Roles For You
Resume Score out of 10

## How to Run
1. Get a free Gemini API key from aistudio.google.com
2. Open index.html
3. Replace YOUR_API_KEY_HERE with your key
4. Open in browser and analyze!

- HTML & CSS
- Bootstrap 5
- JavaScript
